01 / Rights and access

MLS membership is not IDX licensing.

MLS access lets an authorized real estate professional use listing information for brokerage work. IDX is permission to publish specified MLS listing data to consumers, under MLS rules and the applicable broker's authorization.

MLS ACCESS

Professional access

Participant brokers and affiliated subscribers may have their own MLS PIN credentials. An individual login is not a shareable website API key.

IDX RIGHTS

Public-display authorization

Eligible MLS PIN Participants and Subscribers may display permitted IDX data subject to the MLS rules, participant permission, attribution and site requirements.

IDX TECHNOLOGY

Site integration

A service or custom integration fetches and displays permitted listings. Technical vendor subscriptions and MLS authorization are separate questions.

Bottom line: The broker does not have to buy an IDX website merely so the team can have one. The team may run a separate IDX-enabled website subject to the applicable broker approval and MLS PIN requirements. A shared vendor account can sometimes cover two licensed sites; it is not the same as sharing private MLS credentials.

Three workable ownership models

MODEL A

Separate vendor accounts

Independent billing, settings and admin access for the brokerage and team. More expensive but cleanest operational separation.

Maximum control
MODEL B

One account, two website licenses

Discounted additional-site licensing may cut subscription costs. Confirm permission for both branded sites and who owns the master account.

Launch candidate
MODEL C

Custom licensed integration

Use authorized MLS/vendor data access with independently branded front ends and a custom search stack; requires stronger compliance and engineering.

02 / MLS PIN fees · checked October 2026

What does MLS PIN actually charge?

There is not a universal extra monthly “IDX license” charge that every brokerage and team must automatically add to an IDX plugin subscription. MLS PIN publishes different charges for member access, free basic IDX display, a broker’s own feed, and a third-party vendor's feed.

BASIC IDX DISPLAY
$0 / month

Free MLS PIN IDX options

Eligible Participants and Subscribers can link to Pinergy IDX Search pages or manually download IDX data. These do not provide the same native, automated and fully styled SEO experience as a paid IDX integration.

DIRECT BROKERAGE DATA ACCESS
$100 / month

Broker Data Access Agreement

MLS PIN publishes $100/month for a brokerage-approved direct data feed, covering its main office and participating MLS PIN branches. Approval and use restrictions apply; it is not automatically a separate fee on top of Showcase IDX or IDX Broker.

THIRD-PARTY DATA VENDOR
$525 / month

Vendor Data Access Agreement

MLS PIN publishes $525/month for a third-party vendor’s direct data access, regardless of the number of MLS PIN subscribers using that vendor. This is a vendor-level fee, not a $525 charge to every agent or site. A vendor might recover it through its prices.

Separate MLS PIN membership / subscriber cost

MLS PIN's publicly available subscriber agreement lists the following rates, billed quarterly in advance. These are MLS subscription fees, not IDX website license fees. Verify the current subscriber and office rate directly, because the agreement may be revised.

03 / Search visibility

Make the team's domain the asset.

A listing appearing on a website does not guarantee Google will index it, rank it, or pass the team unique SEO value. Duplicated MLS data exists across many real estate sites. The plan must go beyond automated listings.

LOW VALUE FOR SITE SEO

Iframe or outbound MLS link

Consumers can search, but property content typically does not exist as crawlable pages on the team's principal domain.

BETTER FOUNDATION

Indexable, on-domain listings

Clean property URLs, rendered content, controlled metadata, correct canonical tags, sitemaps and internal links can create an opportunity to rank.

DURABLE DIFFERENTIATOR

Original local expertise

Useful Worcester-area neighborhood guides, market coverage, agent bios, buyer/seller resources and original commentary remain assets beyond a vendor.

Important: The team and brokerage can both have IDX pages, but search engines may choose one canonical representative of near-identical listing content. The goal is not merely “two copies of every listing”; it is two distinct sites with authentic brand, audience, internal links and original content.

SEO acceptance tests for any provider

  • View HTML source with JavaScript disabled: is useful property content present?
  • Property detail URLs appear under each primary domain, not an outside domain.
  • Canonical tags point to appropriate authorized URLs.
  • XML sitemaps contain eligible indexable pages.
  • Thin filters and duplicate search combinations do not create crawl traps.
  • Expired/sold listings have an approved ongoing content policy.
  • Listing attribution and display restrictions remain intact.
  • Core Web Vitals remain healthy despite maps/search scripts.
  • Structured data describes visible content truthfully.
  • Search Console, analytics, lead forms and CRM are separately owned.
04 / Build our own

Match the site perfectly — without building an MLS from scratch.

There are three levels of customization. A fully custom search interface does not always require owning a raw MLS data feed. Start by customizing the front end around an approved provider, then replace deeper infrastructure only when legally and commercially justified.

LEVEL 1 · FASTEST

Style a third-party IDX

Use the vendor's WordPress blocks, shortcodes and hooks with scoped CSS design tokens, custom wrappers and approved template options.

Brand match: Good to very good, limited by vendor markup and update stability.

Best for: Launch with minimal data operations.

LEVEL 2 · BALANCED

Custom WP search UI + vendor API

Design custom Gutenberg blocks or PHP templates and build custom filters, cards, maps and lead forms with data from an authorized API and use rights.

Brand match: Excellent where API rights and endpoints allow it.

Best for: Differentiated UI without maintaining an entire feed.

LEVEL 3 · MAX CONTROL

Direct MLS/RESO integration

Build a licensed ingest layer, normalized property store, compliance filters, search index, cache, media service and WordPress rendering.

Brand match: Fully custom.

Best for: Repeatable multi-client product after formal data permissions.

What the integration layer would handle

  • Token/credential management on the server (never browser JavaScript).
  • Incremental updates, status changes, deletes and refresh jobs.
  • RESO data normalization, address/geographic lookup and approved photos.
  • Listing-agent, office and brokerage attribution.
  • Limits on stored data, sold/off-market retention and syndication.
  • Rate limiting, caching, logs, monitoring and error recovery.

What stays inside each WordPress site

  • Reusable property cards, neighborhood grids and interactive maps.
  • Custom Gutenberg blocks and theme.json design tokens.
  • Server-rendered detail pages, SEO metadata and sitemap logic.
  • Agent pages, lead forms, contact routing and CRM integration.
  • Independent domains, copy, imagery and analytics.
  • Fallback behavior when an external listing service is unavailable.
Critical licensing caveat: Access to an MLS PIN feed does not itself authorize caching, republishing, feeding multiple unrelated brokerages, retaining sold data forever, or operating a vendor SaaS. Obtain the exact approved data-use agreements before writing the ingestion system. A broker-authorized website integration and a commercial multi-client IDX platform may need different agreements and fees.

05 / Delivery approach

Launch fast, retain the option to evolve.

Confirm legal authorization

Ask MLS PIN whether ReWAP and its affiliated team can register two IDX domains through one vendor account, and what happens when team affiliation changes.

Test two vendors on staging

Trial Showcase IDX and IDX Broker in the actual WordPress theme. Compare property HTML, URLs, schema, sitemap, styling and lead workflows, not only search demos.

Build original local SEO pages

Publish agent pages, city landing pages, original neighborhood content, guides and conversion pathways from the outset.

Abstract the IDX integration

Use a modest theme/plugin adapter so presentation components and original editorial pages aren't tightly coupled to one vendor.

Evaluate custom API replacement

Only after proving lead-generation value and obtaining permitted API access, prototype a branded search experience and measure ongoing cost/complexity.

06 / Recommendation

Choose portability over platform lock-in.

Phase one

Use WordPress + a validated IDX provider

Begin with a provider such as Showcase IDX if its on-domain listing output, MLS PIN approval and styling meet requirements. Compare IDX Broker for budget. Seek the true two-site pricing and verify ownership access before contracting.

Phase two

Build your own visual system and reusable product

Keep the agent directory, localized content, forms, SEO architecture and design system separate from the IDX feed. Prototype custom API-powered blocks next; consider direct feed infrastructure only when multiple client projects justify it.

Most important rule: The Oberdorfer Team should own its domain, WordPress content, agent pages, Search Console property and lead data arrangement. MLS-fed property content remains subject to MLS and vendor licenses; it is not automatically portable as owned editorial content.
